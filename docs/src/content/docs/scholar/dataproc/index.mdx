# Dataproc Engine

The **dataproc-engine** is an enterprise-grade framework designed to generate high-fidelity industrial datasets for AI agent research. By consolidating 16 distinct sectors into a unified hierarchical fleet, the engine provides a robust foundation for benchmarking agents across finance, healthcare, energy, and the public sector.

## Research-Grade Principles

1. **Source validation**: Inspect the selected provider, retrieved records and provenance; source names such as SEC EDGAR or World Bank do not themselves establish statistical parity.
2.  **Zero-Bundling Architecture**: Keeps source/provenance explicit. Simulation requires opt-in; apply data minimization, source authorization and record validation to sensitive inputs rather than assuming a universal PII guarantee.
3. **Record integrity**: StandardSchema carries an ID, industry, data, provenance and checksum. Factory-generated values depend on input serialization; providers can supply their own IDs/checksums. They are not immutable storage guarantees.
4.  **Multi-Tier Fallback**: Intelligent extraction pipeline that scales from Cloud APIs to local LLMs and regex heuristics.

## Record contract

`dataproc_engine.core.base_provider.StandardSchema` has these fields:

| Field | Meaning |
| --- | --- |
| `id` | Record identifier |
| `industry` | Sector identifier |
| `data` | Provider-specific record dictionary |
| `provenance` | Provider-specific source/retrieval/execution metadata |
| `checksum` | Record checksum |

`to_dict()` flattens `record_id`, `industry`, `checksum`, then provenance and data
into the exported row. Data keys are copied last and can replace earlier keys;
inspect each provider's output rather than assuming identical column sets.
Simulated provenance forces exported `execution_mode: simulated`.
`source_hash` and `veracity_score` are not universal required fields.

## Getting Started

To initialize the engine and run your first extraction for research purposes:

```bash
# Extract finance data from the SEC EDGAR gold standard
python dataproc_engine/cli/main.py extract --industry finance --limit 10

# Results saved to: industries/finance/datasets/finance_kb.jsonl
```

### High-Fidelity Simulations

Researchers can use Dataproc to generate "Lab-Ready" environments. Live-source failures do not silently select simulations. Use `--allow-simulation` to permit simulated fallback deliberately; records retain `simulation: true` and `execution_mode: simulated` in provenance/exports. Validate fidelity for the specific source and fixture; opting in does not prove statistical parity.
