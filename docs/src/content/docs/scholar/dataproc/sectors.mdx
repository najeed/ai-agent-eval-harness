# 16-Sector Industrial Fleet

## Provider architecture and exported records

The pipeline uses BaseProvider subclasses. Extend a provider to implement source
retrieval and transformation for a new dataset; do not rely on a universal
sector Generator API or generic noise-injection contract.

The [standard envelope](/scholar/dataproc/) contains `id`, `industry`, `data`,
`provenance` and `checksum`. Exports flatten the envelope to `record_id`, industry,
checksum and provider-specific data/provenance fields. `veracity_score` and
`source_hash` are not required across all providers. Source names in this table
are references or analogies, not proof that each run contacted that service or
achieved parity. Check actual provenance and simulation flags for every dataset.
