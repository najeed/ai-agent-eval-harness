# GAIA datasets

The GAIA loader maps `Question` / `question` and `Final answer` / `answer` from an
explicitly selected dataset into AES scenarios with source provenance.

Prepare a JSON, JSONL or Parquet file with the real questions and reference
answers, then run:

```bash
agentv run --path gaia://datasets/gaia.jsonl --protocol http --agent http://localhost:5001/execute_task
```

The file must exist. A label such as `gaia://2025_val_t1` is not a built-in version
selector. Use an explicit Hugging Face source with config, split and commit
revision when remote loading is appropriate; see the [benchmark guide](/scholar/benchmarks/).

The loader preserves reference answers and row provenance; it does not provision
the entire GAIA tool environment or supply human tool-efficiency baselines.
Browser tasks need separately installed/configured browser infrastructure and
an agent/tool contract. Treat browser behavior, external data, secrets and state
observations as explicit experimental conditions, not guarantees of the loader.
