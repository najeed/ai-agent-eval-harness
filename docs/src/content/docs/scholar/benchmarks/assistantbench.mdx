# AssistantBench datasets

The AssistantBench loader projects a user-selected question/answer dataset into
AES scenarios. Accepted question fields are `task`, `question` or `Question`;
answer fields include `answer`, `answers` or `Final answer`.

```bash
agentv run --path assistantbench://datasets/assistantbench.jsonl --protocol http --agent http://localhost:5001/execute_task
```

Acquire the real dataset and create the referenced file before execution.
`assistantbench://v1` and similar version labels do not resolve bundled data.
Missing files, empty datasets and malformed records fail explicitly. Local
JSON/JSONL/Parquet and explicit Hugging Face sources use the shared
[dataset-loading contract](/scholar/benchmarks/).

The source tasks determine the benchmark's content. Tool-chain, enterprise-policy
or reconciliation evidence requires the corresponding declared tools, assertions
and independent observations; the loader does not add those capabilities to
arbitrary input rows.
