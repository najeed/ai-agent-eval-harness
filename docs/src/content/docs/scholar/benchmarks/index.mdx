# Load explicit benchmark datasets

GAIA and AssistantBench adapters project existing question/answer records into
AES scenarios. They do not download a dataset from a version-only alias or
substitute synthetic questions when data is absent.

```bash
agentv run --path gaia://datasets/gaia.jsonl --protocol http --agent http://localhost:5001/execute_task
agentv run --path assistantbench://datasets/assistantbench.jsonl --protocol http --agent http://localhost:5001/execute_task
```

Create or acquire these dataset files before running the examples. Local JSON,
JSONL and Parquet are supported; Parquet needs pandas and a Parquet engine.
Hugging Face loading requires the optional `datasets` package and an explicit
source, for example
`gaia://hf://gaia-benchmark/GAIA?config=2023_all&split=validation&revision=COMMIT`.
Select an actual immutable revision. Remote loading is disabled in airgap mode.

Questions and reference answers are required. Missing, empty or malformed sources
fail rather than generating a replacement benchmark. See [GAIA](/scholar/benchmarks/gaia/)
and [AssistantBench](/scholar/benchmarks/assistantbench/) for field mappings.
