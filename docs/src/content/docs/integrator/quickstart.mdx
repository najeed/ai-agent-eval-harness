# Run the bundled demo

The demo runs without provider API keys from a repository checkout. It starts the
local sample HTTP agent, evaluates a bundled telecom scenario, writes reports,
and stops the sample service.

<Steps>

1. **Install from the repository root**
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -e .
   ```
   On macOS/Linux, activate with `source .venv/bin/activate`.

2. **Run the demo**
   ```bash
   agentv quickstart
   ```
   Keep `sample_agent/agent_app.py` and
   `industries/telecom/scenarios/technical_support/13814_home_internet_slow_speed.json`
   available in the checkout. The command executes this scenario; it does not
   download or scaffold a corpus.

3. **Inspect results**
   ```bash
   agentv console
   ```
   Open [the local console](http://localhost:5000). Authenticate using a configured
   key or the first-run bootstrap instructions printed by the console before
   requesting protected run/scenario data.

</Steps>

The demo records execution evidence through the run provider. It is a simulated
baseline, not an authoritative certificate. For your own agent, follow the
[agent contract](/integrator/agent-contract/); certification requires eligible
live evidence and a separate [certification workflow](/auditor/verification/).
